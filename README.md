# 💰 Medical Cost Prediction

## 📌 Project Overview
This project predicts medical insurance cost based on user details using Machine Learning.

## 🚀 Features
- Predicts medical charges instantly
- User-friendly web interface
- Built using Flask
- Works on any device via browser

## 🧠 Machine Learning Model
- Algorithm: Random Forest Regressor
- Accuracy: ~85%+

## 📊 Dataset
- Medical Cost Personal Dataset
- Features:
  - Age
  - Sex
  - BMI
  - Children
  - Smoker
  - Region

## 🛠️ Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- NumPy
- HTML
